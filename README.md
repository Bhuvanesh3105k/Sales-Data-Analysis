# Sales-Data-Analysis

Project Overview

This project analyzes sales data using Python and Power BI to understand business performance and identify useful insights.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

Analysis Performed

- Data Understanding
- Missing Value Analysis
- Duplicate Value Checking
- Product-wise Sales Analysis
- Product-wise Profit Analysis
- Region-wise Sales Analysis
- Monthly Sales Analysis
- Category-wise Sales and Profit Analysis
- Quantity and Discount Analysis

Key Insights

- Laptop generated the highest sales and profit.
- West region recorded the highest sales.
- July recorded the highest monthly sales.
- Electronics generated the highest category-wise profit.

Power BI Dashboard

The Power BI dashboard will present key sales metrics, product performance, regional sales, and monthly trends using interactive visualizations.

Project Goal

To analyze sales performance and support better business decisions through data visualization.
